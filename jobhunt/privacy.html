jobhunt privacy policy

Last updated: 29 October 2026

jobhunt is a personal tool used only by its owner. This page describes how it handles data received from Google APIs.

Data accessed

jobhunt uses the Google Drive API and the Google Sheets API with the drive.file scope. It only accesses files and folders that jobhunt itself created in the owner's Google Drive: folders and documents for job applications, and one tracker spreadsheet. It does not access any other file, contacts, email or calendar data.

How the data is used

jobhunt uses this data only to store and update the owner's job-application documents and to keep the tracker spreadsheet in sync with the owner's own job-search database. Status changes and notes the owner enters in the spreadsheet are read back into that database.

Storage

The OAuth token and the job-search database are stored only on the owner's own server, in files that only the owner's account can read. Backups are kept on the owner's own computer.

Sharing

Data is not sold, shared with or disclosed to third parties, with one exception: to answer the owner's own questions and to prepare application documents, parts of the job-search database (which can include notes and statuses read from the tracker spreadsheet) may be sent to Anthropic's Claude service, which processes them under the owner's own subscription. This data is not used to train AI models.

Limited Use

jobhunt's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Deletion and revoking access

The owner can revoke jobhunt's access at any time at myaccount.google.com/permissions and delete the files it created in Google Drive.
