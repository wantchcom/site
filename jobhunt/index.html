jobhunt

jobhunt is a personal job-search assistant used by one person, Kirill Zverev. It is not offered to the public and has no other users.

It runs on the owner's own server. With the owner's permission it uses Google Drive and Google Sheets to:

  • create a Jobs folder in the owner's Google Drive, with one subfolder per job application containing the resume, cover letter and notes that jobhunt generated;
  • create and update one tracker spreadsheet listing those applications and their status.

jobhunt requests only the drive.file scope. It can see and change only the files it created itself. It cannot read any other file in the owner's Drive.
